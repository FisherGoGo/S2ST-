它主要试图回答四个问题：

1. 语音翻译技术是怎样从传统级联架构发展到直接翻译架构的？
2. 不同模型如何表示语音、理解语言并生成目标语音？
3. 现有 S2ST 模型面临哪些技术困难？
4. 今后还有哪些值得研究的方向？

---

原来的路线是传统级联式： ASR - MT - TTS 
这套模型的问题有：前端的错误会继承到后端，存在延迟，损失语音信息

现在有一种新的方法：直接式 S2ST

语音 -> 语音编码器提取语音特征 -> 语言解码器 -> 声学合成器 -> 声码器

语音翻译模型通常不是直接从一串原始音频采样值预测另一串采样值，而是利用中间的语音表示降低建模难度，两种模型都是如此

论文讨论了几种重要的特征提取方式：

| 技术                | 作用         | 你需要怎样理解        |
| ----------------- | ---------- | -------------- |
| ※Mel-Spectrogram  | 将语音转换成时频特征 | 描述声音在不同频率上的能量  |
| MFCC              | 提取紧凑的声学特征  | 传统语音识别常用特征     |
| wav2vec 2.0       | 自监督学习语音表示  | 从大量语音中学习有用的特征  |
| ※HuBERT           | 学习语音隐藏表示   | 可进一步提取离散语音单元   |
| mHuBERT           | 多语言语音表示学习  | 适用于跨语言任务       |
| Speaker Embedding | 表示说话人的声音特征 | 帮助模型保留音色或适配说话人 |

代表模型

| 模型                         | 核心思路              | 最值得研究的地方                    |
| -------------------------- | ----------------- | --------------------------- |
| Translatotron（2019）        | 语音到声学频谱           | 最早一批有代表性的端到端架构              |
| Translatotron 2（2021/2022） | 加强语言解码、声学生成和音色保留  | 语义与说话人特征如何结合                |
| S2UT（2021/2022）            | 语音到离散单元，再恢复波形     | HuBERT、K-Means、Unit Vocoder |
| UnitY（2023）                | 两阶段：先目标文本表示，再声学单元 | 文本监督与语音生成如何统一               |

存在的问题

| 目前的问题    | 为什么困难           | 值得研究的方向                            |
| -------- | --------------- | ---------------------------------- |
| 平行语音数据不足 | 难以收集同一内容的跨语言语音  | 自监督、合成数据、零样本学习                     |
| 翻译不准确    | 语义理解与跨语言映射困难    | 预训练、多任务学习                          |
| 说话人音色丢失  | 语言内容与音色等特征难以分离  | Speaker Embedding、Voice Conversion |
| 情绪和韵律丢失  | 文本无法完整传递声音表达方式  | 风格迁移、韵律建模                          |
| 生成速度慢    | 长序列预测和声学合成成本高   | 非自回归生成、流式生成                        |
| 噪声与口音影响  | 真实音频和训练数据分布不同   | 数据增强、鲁棒语音编码器                       |
| 质量评价不完整  | 语义、音质、音色和表达方式不同 | 多维评价与人工评价结合                        |
|          |                 |                                    |

同一段英文翻译语音，至少可以从四个角度评价：

1. 翻译准确性： 有没有把中文内容翻译对？
2. 语音自然度： 英语听起来像不像自然的人类语音？
3. 说话人相似度： 是否保留了原说话人的音色？
4. 韵律与情绪： 强调、停顿和情绪是否合理？

文中提到的概念

1. 理解语音表示：Waveform → Mel-Spectrogram
2. 理解语音编码：Encoder、HuBERT、Embedding
3. 理解序列生成：Seq2Seq、Attention、Decoder
4. 理解语音合成：声学模型、Vocoder、TTS
5. 理解完整系统：Translatotron、S2UT、UnitY、ComSpeech
6. 理解质量评价：翻译质量、自然度、音色、韵律
