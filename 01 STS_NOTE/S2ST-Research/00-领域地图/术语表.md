# 术语表

| 术语 | 直观解释 | 去哪里看 |
| --- | --- | --- |
| ASR / STT | 同语言语音转文字；STT 有时被宽泛使用，应查任务定义 | [ASR](../01-基础知识/语音识别-ASR.md) |
| ST / S2TT | 跨语言语音到文字；ST 的含义依论文定义 | [领域总览](领域总览.md) |
| T2TT / MT | 文字翻译成另一语言文字 | [MT](../01-基础知识/机器翻译-MT.md) |
| TTS | 把文字合成为可听波形 | [TTS](../01-基础知识/语音合成-TTS.md) |
| S2ST | 跨语言语音到语音翻译 | [分类](技术路线分类.md) |
| Encoder / Decoder | 提取上下文表示 / 条件生成目标序列 | [Transformer](../01-基础知识/Transformer与Seq2Seq.md) |
| Token / Unit / Codec token | 文本符号 / 语音离散符号 / 压缩编码符号；不能默认互换 | [离散表示](../01-基础知识/语音编码与离散表示.md) |
| Mel spectrogram | 听觉频率刻度上的时频能量特征，不是波形 | [数字音频](../01-基础知识/数字音频基础.md) |
| Vocoder | 根据声学表示生成波形的模块 | [声码器](../01-基础知识/声码器与波形生成.md) |
| AR / NAR | 依赖已生成结果逐步预测 / 某些维度并行预测 | [Transformer](../01-基础知识/Transformer与Seq2Seq.md) |
| Teacher forcing | 训练时把真实前缀喂给解码器 | [Transformer](../01-基础知识/Transformer与Seq2Seq.md) |
| CTC | 将无精确对齐的输入帧与符号序列对齐的一种目标 | [ASR](../01-基础知识/语音识别-ASR.md) |
| MAS | Monotonic Alignment Search；搜索文本到声学帧的单调对齐 | [VITS](../03-模型研究/VITS.md) |
| MOS | 人工主观评分均值，依赖问题与听测设计 | [自然度](../05-质量评价/语音自然度与音质.md) |
| ASR-BLEU | 输出语音先经评价 ASR 转写，再比较目标参考译文 | [语义评价](../05-质量评价/语义与翻译质量.md) |
| RTF | 推理耗时/输入音频时长，需说明计时范围 | [实验协议](../07-实验/实验路线与比较协议.md) |
| Zero-shot | 对某一未见任务/语言/说话人的泛化；须写清“没见过什么” | [ComSpeech](../03-模型研究/ComSpeech.md) |

未理解的术语先在[我的疑问](../08-研究思考/我的疑问.md)写一个带上下文的问题，再补定义，避免只积累词条。
