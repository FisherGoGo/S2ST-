# 研究问题与挑战

以下是待研究的问题，不能据此断定每个模型都存在相同缺陷。

| 问题 | 为什么困难 | 可以观察什么 |
| --- | --- | --- |
| 意义正确且声音自然 | 内容建模和声学建模的目标不同 | 语义评分高但漏字，或内容正确但断句生硬 |
| 跨语言韵律迁移 | 两种语言的词序、音节数、重音规则不同 | 原问句语气是否合理变成目标语言问句 |
| 音色与语言解耦 | 说话人特征会和口音、语料条件混在一起 | 跨语言 speaker embedding 与人工判断是否一致 |
| 平行语音数据稀缺 | 同一内容、双语、多说话人录音难收集 | 合成数据与真实录音之间的差异 |
| 增量输出 | 目标词可能依赖还未听到的源信息 | 首段延迟、修订率、停顿与翻译错误 |
| 长语音与上下文 | 分段会丢指代和跨句信息 | 同一术语是否一致、时间戳是否漂移 |
| 比较是否公平 | 预训练数据、声码器、ASR 评价器都可能不同 | 受控消融与系统整体比较是否分别报告 |

数据稀缺与表示复用见[ComSpeech](../03-模型研究/ComSpeech.md)；韵律和流式的研究入口见[Seamless 系列](../03-模型研究/SeamlessM4T-v2.md)。上表是研究问题整理，不是论文逐条承认的局限。形成实验想法时迁移到[尚未解决的问题](../08-研究思考/尚未解决的问题.md)，并写出证伪条件。
