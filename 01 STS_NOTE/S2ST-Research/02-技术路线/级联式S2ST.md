# 级联式 S2ST：让三个模块真正接起来

系统把任务分解为 ASR、MT、TTS，便于使用现成预训练组件并诊断错误。对应[级联系统研究笔记](../03-模型研究/传统级联系统.md)。

```mermaid
flowchart LR
  A[源音频及采样率] --> B[ASR]
  B --> C[源转写与分段]
  C --> D[MT]
  D --> E[目标译文]
  E --> F[文本规范化及 TTS]
  F --> G[目标波形及采样率]
```

| 接口 | 最少保存什么 | 常见故障 |
| --- | --- | --- |
| 音频→ASR | 原始文件哈希、语言、实际预处理 | 采样率不匹配、静音幻觉 |
| ASR→MT | 原转写、规范化转写、标点与分段 | 专名/数字错误、口语和书面域差异 |
| MT→TTS | 原译文、实际合成文字、目标语言 | 数字读法、中英混读、分词失配 |
| TTS→文件 | 波形、真实采样率、说话人 ID | 写错 WAV 采样率造成变速 |

最朴素组合不需要联合训练。若要适配，分别记录 ASR 的识别目标、MT 的翻译目标、TTS 的声学生成目标；“连接起来”不会自动让损失跨过离散文字端到端传播。

优势是可替换和可观察，也能使用大量非 S2ST 数据；硬文本接口可能丢掉置信度与副语言信息。文本级联不自动保留源音色，需要额外说话人/风格通道和合适生成器。

诊断方法：完整级联 A；人工源转写→MT→TTS 的 B；人工目标译文→TTS 的 C。A/B 比较帮助定位识别影响，B/C 看翻译影响，但指标变化并不具有严格可加性。参见[比较协议](../07-实验/实验路线与比较协议.md)。

来源：[ACL 2020 综述](https://aclanthology.org/2020.acl-main.661/)；三段组件的具体实现见[Whisper](../03-模型研究/Whisper.md)、[NLLB](../03-模型研究/NLLB-200.md)、[MeloTTS](../03-模型研究/MeloTTS.md)。
