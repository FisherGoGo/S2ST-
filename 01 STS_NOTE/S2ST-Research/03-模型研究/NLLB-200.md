# NLLB-200

## 1. 简介与研究背景

把 ASR 的源转写变为目标文字，避免一开始就训练整套语音翻译模型。 路线：基础 MT / 级联中间模块。

## 2. 论文、官方代码与权重

原始论文：[No Language Left Behind: Scaling Human-Centered Machine Translation](https://arxiv.org/abs/2207.04672)；[证据卡 P03](../04-论文阅读/文献/P03-NLLB-200.md)。

代码/文档：[官方代码/文档](https://github.com/facebookresearch/fairseq/tree/nllb)。权重：[预训练权重/官方入口](https://huggingface.co/facebook/nllb-200-distilled-600M)（未下载）。

核验日期：2026-10-27；官方入口可访问不等于本地可运行，下载许可、依赖版本与文件可用性需在实践前检查。

## 3. 核心问题

多语文本翻译及低资源语言覆盖；本地入门候选是 dense distilled 600M。

## 4. 整体架构与数据流

> 源文字 → 带源语言配置的 tokenizer → 文本编码器 → 带目标语言条件的解码器 → 目标文字

此行是模块层示意，不是精确计算图。请在精读后补张量形状、条件输入、残差/注意力和训练专用分支。

[教学简化] tokenizer、embedding、Transformer 编码/解码和语言标记。[来源核实] 原报告讨论 MoE；600M 模型卡是蒸馏变体，不能直接照搬大模型的稀疏专家架构图。
