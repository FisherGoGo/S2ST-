# SeamlessM4T

## 1. 简介与研究背景

从单语言对 S2ST 扩展到共享语音/文字任务和多语数据管线。 路线：统一多任务 / 多语双模态。

## 2. 论文、官方代码与权重

原始论文：[SeamlessM4T: Massively Multilingual & Multimodal Machine Translation](https://arxiv.org/abs/2308.11596)；[证据卡 P08](../04-论文阅读/文献/P08-SeamlessM4T.md)。

代码/文档：[官方代码/文档](https://github.com/facebookresearch/seamless_communication)。权重：[预训练权重/官方入口](https://huggingface.co/facebook/hf-seamless-m4t-large)（未下载）。

核验日期：2026-10-27；官方入口可访问不等于本地可运行，下载许可、依赖版本与文件可用性需在实践前检查。

## 3. 核心问题

用统一系统支持不同输入输出模态及多语言方向。

## 4. 整体架构与数据流

> 源语音或文字 → 对应编码器 → 目标文字/语言表示 → 目标 units → vocoder → 波形（文字任务在文本处结束）
