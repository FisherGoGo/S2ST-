# Whisper

## 1. 简介与研究背景

把多语音频转成文字，作为级联源端和生成音频的评价转写器。两种用途应冻结各自配置。 路线：基础 ASR。

## 2. 论文、官方代码与权重

原始论文：[Robust Speech Recognition via Large-Scale Weak Supervision](https://proceedings.mlr.press/v202/radford23a.html)；[证据卡 P01](../04-论文阅读/文献/P01-Whisper.md)。

代码/文档：[官方代码/文档](https://github.com/openai/whisper)。权重：[预训练权重/官方入口](https://github.com/openai/whisper#available-models-and-languages)（未下载）。

核验日期：2026-10-27；官方入口可访问不等于本地可运行，下载许可、依赖版本与文件可用性需在实践前检查。

## 3. 核心问题

从不同语种和录音条件中识别内容，研究大规模弱监督的泛化。

## 4. 整体架构与数据流

> 源波形 → log-Mel → Transformer 语音编码器 → 文本解码器 → token/文字

此行是模块层示意，不是精确计算图。请在精读后补张量形状、条件输入、残差/注意力和训练专用分支。

## 5. 主要模块功能

[教学简化] 音频前端处理采样和特征；编码器学习时序上下文；解码器在任务/语言 token 条件下输出文字。精确特征帧数和任务序列待方法图核对。

基础关联：[相关概念](../01-基础知识/语音识别-ASR.md)、[路线分类](../00-领域地图/技术路线分类.md)。

## 7. 推理过程

指定源语言并使用 transcribe，生成源文本；translate 用于非英语→英语文字，不是通用双向 S2ST。随后 MT/TTS 是其他模块。
