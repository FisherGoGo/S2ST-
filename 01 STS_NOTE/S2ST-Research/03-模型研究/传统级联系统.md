# 传统级联系统

## 1. 简介与研究背景

第一套可逐模块检查的基线，不是一篇特定论文或一个通用 checkpoint。 路线：ASR → MT → TTS。

## 2. 论文、官方代码与权重

系统配置不是单篇论文；背景与参考见路线说明。

代码/文档：本条无单一官方仓库，或本次未确认。。权重：使用各组件权重，不存在统一的“三段级联权重”。。

核验日期：2026-10-27；官方入口可访问不等于本地可运行，下载许可、依赖版本与文件可用性需在实践前检查。

## 3. 核心问题

用三个独立预训练模块完成中文↔英文语音翻译，并保留可追踪中间产物。

## 4. 整体架构与数据流

> 音频 → Whisper 识别 → 源文字 → NLLB 翻译 → 目标文字 → MeloTTS → 目标音频

此行是模块层示意，不是精确计算图。请在精读后补张量形状、条件输入、残差/注意力和训练专用分支。

## 5. 主要模块功能

ASR、MT、TTS 各自持有配置和语言代码；接口层负责文本规范化、分段与音频元数据。风格/说话人额外通道未接入，初始目标是语义正确的固定声音翻译。

基础关联：[相关概念](../01-基础知识/语音识别-ASR.md)、[路线分类](../00-领域地图/技术路线分类.md)。
