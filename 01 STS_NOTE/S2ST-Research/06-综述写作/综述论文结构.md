# 综述论文结构与证据工作流

## 围绕论证组织材料

引言提出问题和范围；背景统一任务、符号与评价；主体按有解释力的分类比较方法；讨论分析证据强度和真实权衡；挑战和未来方向指出缺口并给出可验证问题。结尾只归纳正文已经支持的判断。

| 写作环节 | 应保存的材料 | 常见需要修正的做法 |
| --- | --- | --- |
| 确定范围 | 任务、语言、生成条件、纳入/排除准则 | 仅按模型名字划范围 |
| 检索筛选 | 查询式、检索日期、命中/排除理由、去重依据 | 看了几篇就称系统性综述 |
| 建立分类 | 训练耦合、目标表示、生成机制、控制与流式轴 | 把所有系统塞进互斥两类 |
| 比较模型 | 可比结果、资源、监督和消融的证据表 | 跨数据集直接排列 BLEU |
| 趋势分析 | 支持和反例、未覆盖的设置 | 用“端到端必然取代级联”代替证据 |
| 挑战与方向 | 谁提出、适用场景、可行检验 | 将自己的想法写成确定创新 |

## 证据到段落

先写问题句，再用两到三篇可比较论文解释机制差异，指出支持条件和未比较部分，最后连接自己的研究问题。避免每段都采用“某年某人提出某模型”的罗列。

每个定量结论保存数据集/划分、语言方向、是否额外预训练、模型规模、生成器、评价器、表号、绝对与相对提升定义。推荐从[论文模板](../04-论文阅读/论文阅读模板.md)抽取，而不是另建一套冲突信息。
