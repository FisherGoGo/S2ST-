# 环境与资源准备

## 已确认与未确认

本次文件创建时可调用 Python 3.13.12，标准库工具已做离线自检。未探测 GPU、未检测完整 CUDA 工具链、未安装深度学习包、未下载模型。硬件能力和真实推理速度待你首次实践时记录。

| 任务 | 资源需求的判断依据 | 下一步前应说明什么 |
| --- | --- | --- |
| WAV 检查与记录 | Python 标准库，按块读音频 | 只支持未压缩 PCM16 WAV，无额外模型 |
| Whisper tiny/base | [官方 README](https://github.com/openai/whisper)的模型规模/显存表；CPU 也可试短音频 | 选多语言 checkpoint、下载体积、FFmpeg、PyTorch/Python 兼容 |
| NLLB distilled 600M | 600M 参数；仅 FP32 参数约 2.4 GB，非完整峰值内存 | 缓存空间、tokenizer、推理精度、实际内存与速度 |
| MeloTTS / VITS | 语言合成权重及前端可能有额外资源 | 精确语言/说话人、音素化/语言模型资源、安装平台限制 |
| SeamlessM4T v2 large | [模型卡](https://huggingface.co/facebook/seamless-m4t-v2-large)约 2.3B 参数；仅 FP16 参数约 4.6 GB，FP32 约 9.2 GB | 激活/工作区还需额外显存；实际包体、精度支持、输入时长、系统 RAM |
| 历史 fairseq 配方/ComSpeech | 代码和编译依赖可能较旧 | 固定 commit、检查 Linux/WSL 路径，确认预训练 checkpoint 真正可得 |

上面参数内存是十进制理论估算，不是显存最低保证。不同 checkpoint 的磁盘文件、前端资源和缓存另算；不要根据参数数字承诺本机运行。

## 环境策略

保持笔记环境轻量，模型按家族隔离虚拟环境；必要时在 WSL2/Linux 运行历史代码，先核对项目要求。先读安装步骤、选择 Python/PyTorch/CUDA 组合并估算资源，再由你决定下载/安装。依赖尚未验证就不制作假装可复现的 lockfile。

建议记录 `python --version`、`python -m pip freeze`、操作系统、GPU/驱动/CUDA（若使用）、模型代码 commit、checkpoint 哈希、随机种子、dtype 和设备。FFmpeg 是外部可执行文件，不等于一个同名 Python 包。

NLLB 官方模型卡当前提示 Transformers v5 的 translation pipeline 已调整；未来实现优先核对直接 `AutoTokenizer`/`AutoModelForSeq2SeqLM` 接口并固定版本。MeloTTS 依赖及 fairseq 不宜未经验证混装。

权重放代码外侧 `models/` 或明确的外部缓存，个人录音放私有数据位置，均不进入笔记 Git。许可条件按具体权重检查，NLLB/Seamless 的模型许可不要从代码仓库许可推断。
