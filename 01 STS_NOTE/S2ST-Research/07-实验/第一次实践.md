# 第一次实践：先检查音频，再准备 Whisper

## 这次练习要留下什么

弄清一个本地录音的采样率、声道、位深、时长和哈希。音频检查成功不代表 ASR 已跑通；两者分别记录。

## A. 不安装依赖的首次操作

准备一段自己有权使用、内容已知的短录音，另存为 PCM 16-bit WAV。建议一段中文、一段英文，文字各含一个数字或专名。保留原文件；不直接把 mp3 改后缀为 wav。检查脚本不会重采样或转换格式。

打开 PowerShell，在以下代码根目录运行：

```powershell
Set-Location -LiteralPath 'D:\Project\Note\Science\STS\02 STS_CODE\S2ST-Research'
python scripts/inspect_audio.py --help
python scripts/inspect_audio.py --input 'D:\你的录音\sample.wav' --output 'audio-check.json'
python scripts/create_run.py --input 'D:\你的录音\sample.wav' --config configs/cascade.example.json --output runs/exp-001
```

把示意输入路径替换为你的真实录音；输出文件已存在时命令拒绝覆盖，换新名字即可。`create_run` 只创建记录，不执行级联。检查结果的 `zero_sample_fraction` 是精确零样本比例，**不是** VAD 静音时长；端点比例只提示数字幅值饱和，也不是完整失真评价。

复制[实验模板](实验记录模板.md)建立一份笔记，填实际命令、输入、采样率和输出路径。听一遍，手写源转写，并解释 $N/f_s$ 为什么是时长。采样率不符时先查[数字音频](../01-基础知识/数字音频基础.md)，不要改文件头。

## B. 下一步才是真实 Whisper 推理

先读[资源与环境](环境与资源准备.md)，盘点 Python、FFmpeg、CPU/GPU、磁盘和 checkpoint 获取方式。当前机器只确认可用 Python 3.13.12；未测试 Whisper/MeloTTS/fairseq 对该版本的兼容性。可选择隔离 Python 3.11 环境，具体版本以组件仓库支持和实测为准，本次不自动安装。

当你主动准备好依赖与本地多语言 checkpoint 后：

```powershell
python scripts/transcribe_whisper.py --input 'D:\你的录音\sample.wav' --checkpoint 'D:\模型目录\tiny.pt' --language zh --device cpu --output runs/exp-001/source_asr.json
```

示例 `tiny.pt` 需提前明确下载；不要选中文任务不支持的 `.en` checkpoint。脚本只用 `transcribe`，不把 Whisper 英文翻译功能当成中英双向 MT。输出含原始文本、分段及模型/输入 hash，手动核对数字、专名、漏字，再在模板里更新模型运行状态。

**成功标准**：A 是“检查工具成功读取真实录音并理解数据”；B 是“真实本地 checkpoint 产生可核对转写”。没有执行 B 时保留“Whisper 未运行”。不要把本次工具自检的合成正弦波当作语音测试集。
