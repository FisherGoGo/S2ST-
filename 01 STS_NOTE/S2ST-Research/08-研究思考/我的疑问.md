# 我的疑问

保留自己的解释比只贴定义更重要。下面是问题种子，不是要求你一次答完的作业。

- 我能否根据一个音频张量的 shape 判断哪一维是时间？还缺哪项接口信息？
- Whisper 的 `transcribe` 与 `translate` 输出语言怎样不同？为什么后者不是通用中英双向 S2ST？
- 文本生成的 token 和 HuBERT unit 都是整数，为什么不能共用 tokenizer 和声码器？
- VITS 的 posterior encoder 在训练时看到什么？推理时为什么不能再输入真实目标语音？
- UnitY 两阶段之间传递硬文字还是隐藏状态？梯度经过哪里？待精读确认。
- ComSpeech 的“无需平行语音”具体指哪一种配对，是否仍需要 S2TT 和 TTS 的标注？
- 为什么翻译正确、声音自然、音色相似可能得到彼此冲突的排序？
