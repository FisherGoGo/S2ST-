# 附件约定

本目录放小型、可公开分享的架构图、论文图的适当摘录及自己的示意图，不自动下载整库 PDF。命名示例：`P07-fig1-two-pass-notes.png`，旁边记录来源、页码、图号和个人改画说明。

音频原件、数据集与权重放代码侧 `data/`、`models/` 或明确外部路径，避免让 Obsidian 索引和同步处理大型二进制。论文 PDF 可由外部文献管理工具管理，保留准确题录链接；不是要求现在安装任何工具。

图若是自己画的简化架构，标明“教学简化”，不能将它当作原论文完整计算图。返回[知识库首页](../README.md)。
