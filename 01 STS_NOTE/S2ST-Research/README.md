# S2ST 科研知识库

这是围绕“跨语言语音生成”持续维护的个人研究项目。当前目标是读懂模块、跑通推理、建立可核对的比较证据，逐步形成综述。这里没有学习日程，也没有已完成模型复现的暗示。

**当前状态（2026-10-27）：基础文档与实验骨架已建立；代表论文完成题录、摘要或指定章节核验；尚未逐篇精读、下载权重或运行真实模型。** 本库选取的是研究起点，不宣称覆盖截至今天的全部前沿成果。

## 目录分工

- `00` 是地图，`01` 解释概念，`02` 比较路线。
- `03` 每个模型一份持续笔记；`04` 按论文保存证据，模型和论文并非一一对应。
- `05` 负责评价的适用范围；`06` 将证据转成综述论证。
- `07` 放方案和记录，`08` 放疑问与可检验假设；`09-附件` 预留图和小附件，`99` 放模板、维护规则与本次文件清单。
- 实际 Python 源码复用外侧目录：[实验代码](../../02%20STS_CODE/S2ST-Research/README.md)。Obsidian 只把 `01 STS_NOTE` 视为仓库；跨仓库相对链接由编辑器打开时可能受限，备用绝对路径见实验 README。

## 内容可信度与阅读状态

“已核实”只适用于旁边所指的来源和具体断言，不表示整篇论文已读懂。摘要声称的改善不能代替逐表核对。正文使用以下标签：

- **[来源核实]** 原始题录、摘要、指定章节或官方文档支持，注明链接及核验范围。
- **[教学简化]** 为理解数据流所作的概括；精确模块以论文版本和代码为准。
- **[作者局限]** 必须有原文节号/页码；未查到就写待阅读。
- **[研究假设]** 我们提出的问题，尚无实验支持。
- **[本地证据]** 仅用于真实执行过、有命令和输出的实验。

阅读状态统一为：`待阅读` → `摘要核验` → `方法已读` → `实验已核对` → `形成批判笔记`。状态不按日期自动升级。初稿中有教学材料，不等于你的理解已经完成。

## 每次新增内容的最小维护动作

先检索是否已有同名模型/论文；新增笔记后更新所属索引；给关键断言加来源与定位；留下一个自己能回答的问题和一个还不懂的问题。真实实验必须链接记录和输出。遵循[维护规范](99-维护与模板/知识库维护规范.md)，不在 Git 中放权重、私人录音和大数据集。
