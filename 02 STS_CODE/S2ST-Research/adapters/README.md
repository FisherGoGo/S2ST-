# 模型适配器接口合同（待实现）

目前无 MT/TTS/统一模型适配器；这是后续实现边界，不是可运行 API 承诺。

| 阶段 | 明确输入 | 明确输出 | 外部依赖与待核对项 |
| --- | --- | --- | --- |
| ASR | 本地音频、checkpoint、源语言、设备 | 源转写/时间段、hash 与耗时 | 已提供可选 Whisper CLI；真实模型未验证 |
| MT | UTF-8 源文本、源/目标 tokenizer 语言码、本地模型路径 | 原始目标译文/生成配置 | Transformers/PyTorch/SentencePiece；版本、forced BOS 与截断策略 |
| TTS | 目标文字、语言、speaker_id、本地合成与前端资源 | WAV、真实采样率、实际合成文字 | MeloTTS 或 VITS 各自环境；数字/音素前端、资源缓存 |
| 级联 | 一个 source sample 与已就绪三个组件 | 各阶段中间物、最终 WAV、分阶段计时 | 按文件先串通，不强求模型同进程 |
| 统一式 | 音频、task/方向、匹配 processor/model、精度 | 文字及/或音频、真实采样率 | Seamless checkpoint 对应版本与资源 |
| 评价 | 输入/输出和人工参考、冻结评价器 | 逐样本原始输出、分维度分数与失败 | 指标库/checkpoint/规范化/人工协议均需版本化 |

禁止适配器导入时联网、自动安装或训练；真实运行要求显式模型位置/缓存，异常向上报告并保留输入 ID。先用本地音频和人工文字对照验证，再实现批量比较。ASR/MT 的语言代码和 TTS 的语言枚举不是同一种格式。
