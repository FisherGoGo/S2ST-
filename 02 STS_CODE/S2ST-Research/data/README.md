# 数据约定

`samples.example.jsonl` 是无真实录音的元数据格式示例，所有路径与参考均需填真实值；不允许把占位行当作测试样本。每行是一条输入，使用稳定 sample_id，双方向分开。

真实数据可放 `data/private/` 或仓库外：保留原始音频及 hash、录音来源/授权、匿名 speaker_id、人工源转写、人工目标参考、采样率/预处理、划分。`reference_target_audio` 不是翻译必需，但需要声学参考时应明确来源和是否合成。

若实验代码在不同环境运行，交换接口为 UTF-8 文本/JSON 与带真实采样率的 WAV。不要把录音内容、个人身份或大数据集写入公共仓库。默认 data 只跟踪本说明及无内容示例。
